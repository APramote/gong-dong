# กองดอง (Gong-Dong)

แอปจัดการหนังสือสำหรับนักอ่านและนักสะสม — PWA ใช้ได้ทั้งมือถือและคอมพิวเตอร์ เก็บข้อมูลในเครื่อง (IndexedDB)

## ที่ทำแล้ว (งานข้อ 1)

- คลังหนังสือ: เพิ่ม/แก้/ลบ, ค้นหา, กรองตามสถานะและที่เก็บ
- ที่เก็บ 3 ประเภท: ตู้หนังสือ (หลายชั้นวาง), วางกอง, กล่อง
- ย้ายหนังสือระหว่างที่เก็บ และจัดลำดับในชั้น/กอง

## ที่ทำแล้ว (งานข้อ 2 ส่วนแรก)

- ถ่ายรูปปก (เล่มเดียวหรือวางเรียงหลายเล่มในรูปเดียว แต่ละเล่มได้รูปปกที่ตัดจากรูป) หรือถ่ายสันปกหลายเล่ม ให้ AI อ่านชื่อเรื่อง ผู้แต่ง สำนักพิมพ์ แล้วตรวจสอบก่อนบันทึก ถ่ายเพิ่มหรือเลือกหลายรูปเข้าชุดเดียวกันได้
- สแกนบาร์โค้ด ISBN หรือพิมพ์ ISBN เพื่อค้นข้อมูลจาก Google Books / Open Library
- รูปปกประจำเล่ม
- หน้าตั้งค่า: เลือก AI ระหว่าง Gemini (ฟรีภายในโควตา) กับ Claude (จ่ายตามใช้) ใส่ API key (เก็บในเครื่องเท่านั้น) และเลือกรุ่น
- ให้ AI ค้นเว็บ (Google Search ผ่าน Gemini หรือ web search ของ Claude) เพื่อเติมเรื่องย่อ คำโปรย สรุปรีวิว และข้อมูลที่ยังว่าง พร้อมลิงก์แหล่งข้อมูล

## ที่ทำแล้ว (งานข้อ 3)

- หยิบไปอ่าน: หยิบจากหน้าหนังสือหรือปุ่ม "หยิบ" ในที่เก็บ หนังสือออกจากที่เก็บและไปอยู่ "ในมือ"
- จับเวลาอ่าน (เริ่ม/หยุดได้หลายรอบ)
- วางคืน: บันทึกหน้าที่คั่น เวลาอ่านจริง และเลือกวางคืนที่เดิมหรือที่อื่น ติ๊ก "อ่านจบ" อัตโนมัติเมื่อถึงหน้าสุดท้าย
- ประวัติการอ่านรายเล่ม และหน้า "กำลังอ่าน" พร้อมสถิติ (ดองอยู่ เวลาอ่าน หน้า อ่านจบ เข้าคลังเดือนนี้)

## ที่ทำแล้ว (งานข้อ 4)

- ถ่ายรูปเพิ่มตู้ กอง หรือกล่อง: ตู้เก็บเฉพาะโครงสร้าง (จำนวนชั้น ลิ้นชัก บานกระจก ขา สี) ไม่รับหนังสือจากรูปทั้งตู้ เพื่อความแม่นยำ แล้วเพิ่มหนังสือทีละชั้นจากหน้าตู้ ส่วนกองและกล่องไม่ใช้ AI แค่จำรูปไว้ หนังสือเพิ่มภายหลัง
- ตู้หนังสือแสดงแบบ 3D (หมุน ซูม แตะเล่มเพื่อหยิบไปอ่านหรือเปิดดู) ความหนาของเล่มตามจำนวนหน้า สีตามรูป
- รูปทรงตู้: ลิ้นชักด้านล่าง บานกระจก (เปิดปิดได้) ขาตู้ — AI ดูจากรูป และแก้เองได้
- ชั้นที่ 1 คือชั้นล่างสุด
- ลิ้นชักแต่ละช่องเป็นที่เก็บหนังสือ แตะลิ้นชักใน 3D เพื่อเปิดดูหนังสือข้างใน
- กองและกล่องไม่มี 3D แต่จำรูปที่ถ่ายไว้ (ไม่ใช้ AI ไม่ต้องมี API key) ถ่ายใหม่หรือเลือกรูปภายหลังได้

## ปิดการใช้ AI

- ตั้งค่า → "ใช้ AI": ปิดแล้วแอปไม่ส่งรูปหรือข้อมูลให้ AI เลย ซ่อนปุ่มที่ใช้ AI ทั้งหมด key ที่บันทึกไว้ยังอยู่
- ยังใช้ได้ตอนปิด: สแกน ISBN, กรอกเอง, ถ่ายรูปกองและกล่อง, จัดระเบียบเบื้องต้น และสถิติ

## หมวดหมู่

- หมวดเป็นตารางของตัวเองในฐานข้อมูล หนังสืออ้างถึงหมวดตามรหัส เปลี่ยนชื่อครั้งเดียวมีผลทุกเล่ม
- หน้าหมวดหมู่ (คลัง → หมวดหมู่): เพิ่ม เปลี่ยนชื่อ (ชื่อซ้ำกับหมวดที่มี = รวมหมวด) ลบ (หนังสือไม่หาย) และแตะเพื่อดูหนังสือในหมวด
- คลังกรองตามหมวดได้ และค้นหาด้วยชื่อหมวดได้ หมวดจาก ISBN หรือ AI เป็นคำแนะนำให้กดใช้

## จัดระเบียบและสถิติ

- จัดระเบียบ (หน้าที่เก็บ → จัดระเบียบ): ตรวจจากกฎโดยไม่ใช้ AI (เล่มเก่าที่ควรลงกล่อง เล่มดองที่อยู่ในกล่อง เล่มไม่มีที่เก็บหรือไม่มีหมวด) และให้ AI จัดหมวดทั้งคลังพร้อมเสนอแผนย้าย เลือกได้ว่าจะใช้ข้อไหน
- สถิติ: เป้าเวลาอ่านต่อวันและเล่มต่อปี อ่านต่อเนื่องกี่วัน เวลาอ่านรายวัน ช่วงเวลาและวันที่อ่าน อ่านจบเทียบกับเพิ่มเข้าคลัง สถานะและหมวด ข้อความประจำวัน และแนะนำเล่มถัดไป

## สำรองและซิงก์ข้อมูล

อยู่ในหน้าตั้งค่า

- **ไฟล์สำรอง:** สำรองข้อมูลทั้งหมด (เลือกรวมรูปได้) เป็นไฟล์ JSON ไฟล์เดียว และกู้คืนจากไฟล์ การกู้คืนเป็นการรวมข้อมูล ไม่ลบของที่มีอยู่
- **Google Drive:** กด "ซิงก์ตอนนี้" เพื่อรวมข้อมูลกับไฟล์ในโฟลเดอร์ข้อมูลของแอป (`appDataFolder`) แอปเห็นเฉพาะไฟล์ของตัวเอง รายการเดียวกันใช้ฉบับที่แก้ล่าสุด การลบตามไปทุกเครื่อง
- โทเคนของ Google เก็บในหน่วยความจำเท่านั้น ไม่บันทึกลงเครื่อง

ตั้งค่าครั้งแรก (ทำครั้งเดียว):

1. console.cloud.google.com → สร้างโปรเจกต์ → เปิดใช้ **Google Drive API**
2. **OAuth consent screen**: External ใส่อีเมลของตัวเองเป็น Test user
3. **Credentials → OAuth client ID → Web application** ใส่ที่อยู่ของแอปใน Authorized JavaScript origins (เช่น `https://<ชื่อผู้ใช้>.github.io`)
4. วาง Client ID ในหน้าตั้งค่าของแอป (ค่านี้ไม่ใช่รหัสลับ) ทำซ้ำข้อนี้ในทุกเครื่องที่ใช้

## คำสั่ง

```bash
npm install
npm run dev      # เปิดแอปตอนพัฒนา
npm test         # ทดสอบชั้นข้อมูล
npm run build    # สร้างไฟล์สำหรับโฮสต์ใน dist/
```

ข้อความในแอปทั้งหมดอยู่ที่ `src/th.ts`
