# กองดอง (Gong-Dong)

แอปจัดการหนังสือสำหรับนักอ่านและนักสะสม — PWA ใช้ได้ทั้งมือถือและคอมพิวเตอร์ เก็บข้อมูลในเครื่อง (IndexedDB)

## ที่ทำแล้ว (งานข้อ 1)

- คลังหนังสือ: เพิ่ม/แก้/ลบ, ค้นหา, กรองตามสถานะและที่เก็บ
- ที่เก็บ 3 ประเภท: ตู้หนังสือ (หลายชั้นวาง), วางกอง, กล่อง
- ย้ายหนังสือระหว่างที่เก็บ และจัดลำดับในชั้น/กอง

## ที่ทำแล้ว (งานข้อ 2 ส่วนแรก)

- ถ่ายรูปปก หรือถ่ายสันปกหลายเล่ม ให้ Gemini อ่านชื่อเรื่อง ผู้แต่ง สำนักพิมพ์ แล้วตรวจสอบก่อนบันทึก
- สแกนบาร์โค้ด ISBN หรือพิมพ์ ISBN เพื่อค้นข้อมูลจาก Google Books / Open Library
- รูปปกประจำเล่ม
- หน้าตั้งค่า: เลือก AI ระหว่าง Gemini (ฟรีภายในโควตา) กับ Claude (จ่ายตามใช้) ใส่ API key (เก็บในเครื่องเท่านั้น) และเลือกรุ่น
- ให้ AI ค้นเว็บ (Google Search ผ่าน Gemini หรือ web search ของ Claude) เพื่อเติมเรื่องย่อ คำโปรย สรุปรีวิว และข้อมูลที่ยังว่าง พร้อมลิงก์แหล่งข้อมูล

## ที่ทำแล้ว (งานข้อ 3)

- หยิบไปอ่าน: หยิบจากหน้าหนังสือหรือปุ่ม "หยิบ" ในที่เก็บ หนังสือออกจากที่เก็บและไปอยู่ "ในมือ"
- จับเวลาอ่าน (เริ่ม/หยุดได้หลายรอบ)
- วางคืน: บันทึกหน้าที่คั่น เวลาอ่านจริง และเลือกวางคืนที่เดิมหรือที่อื่น ติ๊ก "อ่านจบ" อัตโนมัติเมื่อถึงหน้าสุดท้าย
- ประวัติการอ่านรายเล่ม และหน้า "กำลังอ่าน" พร้อมสถิติ (ดองอยู่ เวลาอ่าน หน้า อ่านจบ เข้าคลังเดือนนี้)
