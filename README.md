# กองดอง (Gong-Dong)

แอปจัดการหนังสือสำหรับนักอ่านและนักสะสม เป็น PWA ใช้ได้ทั้งมือถือและคอมพิวเตอร์ ภาษาไทย
ข้อมูลเก็บในเครื่อง (IndexedDB) และซิงก์กับ Google Drive ของผู้ใช้เองได้ ไม่มีเซิร์ฟเวอร์กลาง

## ความสามารถ

**คลัง**
- เพิ่มหนังสือ: ถ่ายรูปปก (หลายเล่มในรูปเดียวได้) ถ่ายสันปกทั้งชั้น สแกน ISBN หรือกรอกเอง
- ให้ AI ค้นเรื่องย่อ คำโปรย และสรุปรีวิวจากเว็บ
- หมวด แท็ก ค้นหา และกรองตามสถานะ ที่เก็บ หมวด
- ข้อมูลนักสะสม: ฉบับ สภาพ ราคา วันที่และร้านที่ซื้อ ลายเซ็น
- ชุดหนังสือ (บอกเล่มที่ขาด) ประโยคที่ชอบ (พิมพ์เองหรือถ่ายหน้าหนังสือให้ AI ถอด)
- สุ่มจากกองดอง เช็กก่อนซื้อ และรายการอยากได้

**อ่าน**
- หยิบหนังสือติดตัวได้หลายวัน บันทึกการอ่านด้วย "คั่นหน้า" (อ่านถึงหน้าไหน ใส่เวลาได้ถ้าต้องการ ไม่ใส่แอปประมาณให้)
- จับเวลาเป็นตัวเลือก วางคืนที่เดิมหรือที่ใหม่ และติ๊กอ่านจบ

**ที่เก็บ**
- ตู้หนังสือ (ชั้นที่ 1 อยู่ล่างสุด มีลิ้นชัก บานกระจก ขาตู้) กอง และกล่อง
- เพิ่มที่เก็บจากรูปถ่าย ดูตู้แบบ 3D ดูที่เก็บเป็นการ์ดรูปหรือรายการ
- พิมพ์ป้ายกล่องและกองพร้อม QR ให้ AI ช่วยจัดระเบียบและจัดหมวด

**สถิติ**
- เป้ารายวันสองแบบ (หน้า และนาที) เป้าอ่านจบต่อปี วันอ่านต่อเนื่อง กราฟรายวัน ช่วงเวลา และรายเดือน
- สรุปปี บันทึกหรือแชร์เป็นรูป มูลค่าคลังจากราคาที่บันทึก

## AI

- เลือกใช้ Gemini หรือ Claude ใส่ API key ในหน้าตั้งค่า (เก็บในเครื่องเท่านั้น ส่งให้ผู้ให้บริการโดยตรง)
- ปิด AI ได้ทั้งหมดด้วยสวิตช์เดียว: แอปไม่ส่งรูปหรือข้อมูลหนังสือให้ AI และซ่อนปุ่มที่ใช้ AI
- เมื่อปิด AI ยังใช้ได้: สแกน ISBN (ส่งเลข ISBN ไป Google Books และ Open Library) กรอกเอง ถ่ายรูปกองและกล่อง จัดระเบียบเบื้องต้น และสถิติ

## สำรองและซิงก์ข้อมูล

อยู่ในหน้าตั้งค่า

- **ไฟล์สำรอง:** สำรองข้อมูลทั้งหมด (เลือกรวมรูปได้) เป็นไฟล์ JSON ไฟล์เดียว และกู้คืนจากไฟล์ การกู้คืนเป็นการรวมข้อมูล ไม่ลบของที่มีอยู่
- **Google Drive:** กด "เข้าสู่ระบบ Google" ครั้งเดียว แอปรวมข้อมูลกับไฟล์ในโฟลเดอร์ข้อมูลของแอป (`appDataFolder`) แอปเห็นเฉพาะไฟล์ของตัวเอง รายการเดียวกันใช้ฉบับที่แก้ล่าสุด การลบตามไปทุกเครื่อง
- **ซิงก์อัตโนมัติ:** หลังการแก้ไขครั้งล่าสุด 1 นาที ขณะที่สิทธิ์จาก Google ยังอยู่ (ราว 1 ชั่วโมง) เมื่อสิทธิ์หมดจะมีแถบให้กดซิงก์ครั้งเดียว
- **ล้างข้อมูล:** ล้างเฉพาะสถิติการอ่าน หรือล้างทั้งหมด (เลือกลบสำเนาใน Drive ด้วยได้)
- โทเคนของ Google เก็บในหน่วยความจำเท่านั้น ไม่บันทึกลงเครื่อง
- ข้อมูลที่รับเข้าจาก Drive หรือไฟล์สำรองถูกตรวจชนิดและคัดเฉพาะฟิลด์ที่รู้จักก่อนบันทึก
- ข้อควรรู้ด้านความปลอดภัย: สคริปต์เข้าสู่ระบบของ Google โหลดเข้ามาในหน้าแอปเฉพาะตอนกดเข้าสู่ระบบ/ซิงก์ และเว็บอื่นใต้ `<ชื่อผู้ใช้>.github.io` ใช้พื้นที่เก็บข้อมูลของเบราว์เซอร์ร่วมกัน (รวม API key ของ AI) ถ้าต้องการแยกขาด ให้ตั้งโดเมนของแอปเอง

ตั้งค่าครั้งแรก (ทำครั้งเดียว):

1. console.cloud.google.com → สร้างโปรเจกต์ → เปิดใช้ **Google Drive API**
2. **OAuth consent screen**: External ใส่อีเมลของตัวเองเป็น Test user
3. **Credentials → OAuth client ID → Web application** ใส่ที่อยู่ของแอปใน Authorized JavaScript origins (เช่น `https://<ชื่อผู้ใช้>.github.io`)
4. ใส่ Client ID เป็นค่า `DEFAULT_GOOGLE_CLIENT_ID` ใน `src/lib/settings.ts` (ค่านี้ไม่ใช่รหัสลับ) หรือวางในหน้าตั้งค่า หัวข้อ "ใช้ Client ID ของตัวเอง"

## คำสั่ง

```bash
npm install
npm run dev      # เปิดแอปตอนพัฒนา
npm test         # ทดสอบชั้นข้อมูล การคำนวณ และการซิงก์
npm run build    # สร้างไฟล์สำหรับโฮสต์ใน dist/
```

ข้อความในหน้าจออยู่ที่ `src/th.ts` (ข้อความที่ประกอบจากการคำนวณบางส่วนอยู่ใน `src/lib`)
