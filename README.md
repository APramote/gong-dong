# กองดอง (Gong-Dong)

แอปจัดการหนังสือสำหรับนักอ่านและนักสะสม — PWA ใช้ได้ทั้งมือถือและคอมพิวเตอร์ เก็บข้อมูลในเครื่อง (IndexedDB)

## ที่ทำแล้ว (งานข้อ 1)

- คลังหนังสือ: เพิ่ม/แก้/ลบ, ค้นหา, กรองตามสถานะและที่เก็บ
- ที่เก็บ 3 ประเภท: ตู้หนังสือ (หลายชั้นวาง), วางกอง, กล่อง
- ย้ายหนังสือระหว่างที่เก็บ และจัดลำดับในชั้น/กอง

## ที่ทำแล้ว (งานข้อ 2 ส่วนแรก)

- ถ่ายรูปปก หรือถ่ายสันปกหลายเล่ม ให้ Gemini อ่านชื่อเรื่อง ผู้แต่ง สำนักพิมพ์ แล้วตรวจสอบก่อนบันทึก
- สแกนบาร์โค้ด ISBN หรือพิมพ์ ISBN เพื่อค้นข้อมูลจาก Google Books / Open Library
- รูปปกประจำเล่ม
- หน้าตั้งค่า: ใส่ Gemini API key (เก็บในเครื่องเท่านั้น) และเลือกรุ่น
- ให้ AI ค้นเว็บ (Google Search ผ่าน Gemini) เพื่อเติมเรื่องย่อ คำโปรย สรุปรีวิว และข้อมูลที่ยังว่าง พร้อมลิงก์แหล่งข้อมูล

## แผนถัดไป

3. หยิบไปอ่าน / วางคืน, คั่นหน้า, สถิติ
4. มุมมอง 3D ของตู้ กอง กล่อง
5. Sync ผ่าน Google Drive
6. เก็บงาน PWA และโฮสต์

## คำสั่ง

```bash
npm install
npm run dev      # เปิดแอปตอนพัฒนา
npm test         # ทดสอบชั้นข้อมูล
npm run build    # สร้างไฟล์สำหรับโฮสต์ใน dist/
```

ข้อความในแอปทั้งหมดอยู่ที่ `src/th.ts`
